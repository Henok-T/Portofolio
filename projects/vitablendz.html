Work / Website

Vitablendz juice shop

A brochure-style website for a juice shop concept, built to practice product presentation, visual hierarchy, and responsive layout.

Overview

The site needed to feel appetizing without becoming a photography gallery. The work focused on a simple page structure that a small shop could actually maintain.

Challenge

Food sites often collapse into large images and weak text. The constraint here was to keep the design readable and structured using only HTML, CSS, and Bootstrap.

Approach

Start with sections a visitor expects — introduction, products, and a reason to get in touch — then use Bootstrap’s grid for consistent spacing across breakpoints.

Technologies

HTML, CSS, Bootstrap.

Key features

  • Product-forward layout for a juice menu
  • Responsive grid for phones and desktops
  • Reusable section patterns for later pages

Results

This remains a public training and portfolio piece rather than a measured commercial launch. No traffic or sales figures are claimed.
