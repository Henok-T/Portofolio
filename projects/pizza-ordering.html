Work / Interactive front end

Pizza ordering interface

A browser-based ordering flow that behaves like a simple cart: choose items, adjust the order, and see the running total.

Overview

The project was built to practice JavaScript interaction on top of a clear menu layout, without introducing a server or payment provider.

Challenge

Static restaurant pages rarely teach state. The hard part was keeping selections, quantities, and totals in sync while the page stayed understandable.

Approach

Model the order in the page’s JavaScript, update the visible cart when a choice changes, and keep the markup semantic enough that the interface still makes sense if styling is delayed.

Technologies

HTML, CSS, JavaScript.

Key features

  • Menu presentation
  • Cart-style order assembly
  • Client-side totals

Results

Training project. No live-order metrics are attached to this page.
