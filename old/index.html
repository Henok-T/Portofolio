Services

What I can help with

Work is scoped around real problems: a site that needs to ship, an application that needs attention, or a process that is slower than it should be.

Web design & development

Responsive websites built with clean HTML, CSS, and JavaScript. Suitable for small businesses, restaurants, and service pages that need to be fast and easy to update later.

  • Landing pages and multi-section sites
  • Responsive layouts for phones and desktops
  • Front-end work in React when the project needs it

Website maintenance

Fixes, small feature additions, and cleanup so an existing site stays readable, consistent, and usable after launch.

  • Layout and styling corrections
  • Content and navigation updates
  • Browser and device checks

Technical support

Production and application support drawn from current Tier-3 work: incident review, defect follow-through, and coordination with internal teams.

  • Issue investigation and reproduction
  • Debugging and testing existing products
  • Clear communication with stakeholders

Software & internal tools

Small applications that remove friction for a team — calculators, data-backed forms, and focused utilities rather than oversized platforms.

  • ASP.NET MVC applications
  • SQL-backed workflows
  • Lightweight Node.js services

Website optimization

Practical improvements to structure, readability, and performance so pages load cleanly and make sense to both people and search engines.

  • Semantic markup and heading structure
  • Responsive behavior and spacing
  • Straightforward on-page SEO basics

Troubleshooting assistance

Help isolating why something is failing — a form, a page, a query, or a process — and documenting the fix so the same issue is easier to handle next time.

  • Root-cause notes, not just patches
  • Code review for student and team projects
  • Guidance on what to change first
